## 01 // Project Overview

This collaborative digital forensics project focuses on investigating image authenticity and identifying potential AI-generated images through multiple forensic techniques.

Three digital images were examined using five forensic tools to evaluate their origin, metadata, compression patterns, pixel inconsistencies, and CFA artifacts.

The investigation combined multiple sources of forensic evidence rather than relying on a single detection method.

---

## 02 // Project Objectives

- Examine the authenticity of digital images.
- Identify potential AI-generated content.
- Analyze image metadata and EXIF information.
- Investigate compression and pixel inconsistencies.
- Perform reverse image searches.
- Verify original image sources.
- Correlate forensic findings across multiple tools.
- Document evidence-based conclusions.

## 07 // Forensic Analysis Techniques

### Reverse Image Search

Google Lens was used to investigate image origins, identify potential online matches, and trace original sources.

### Error Level Analysis (ELA)

FotoForensics was used to examine JPEG compression patterns and identify potential inconsistencies within the images.

### Clone Detection

Forensically was used to examine repeated pixel patterns and identify potentially duplicated image regions.

### Metadata and EXIF Analysis

AperiSolve was used to examine image properties, embedded metadata, dimensions, and compression characteristics.

### Color Filter Array (CFA) Analysis

A Python-based analysis script was used in Google Colab to examine CFA-related artifacts and compare the results across the three evidence samples.

## 10 // Investigation Limitations

- Missing EXIF metadata does not necessarily indicate AI-generated content.
- Reverse image search may not identify every authentic image.
- Compression and editing can influence ELA results.
- CFA artifact counts alone cannot establish image authenticity.
- The reported confidence levels represent investigative judgments rather than statistically validated probabilities.

Forensic conclusions should be supported by multiple sources of evidence.
